# 🎓 Student Database Management System

A simple and user-friendly Student DBMS built using Flask and MySQL.

## 🚀 Features
- Login Authentication
- Add Student
- View Student
- Update Student
- Delete Student
- Dashboard UI

## 🛠 Tech Stack
- Python (Flask)
- MySQL
- HTML, CSS, JavaScript

## ▶ How to Run

```bash
pip install -r requirements.txt
python app.py
